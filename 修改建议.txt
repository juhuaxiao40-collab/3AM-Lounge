这是网页游戏、GalGame项目里最常见的问题之一。

你的问题本质上是：

> 你的人物位置是按照电脑屏幕尺寸摆放的，但手机屏幕尺寸完全不同，所以素材发生了偏移。



一般新手做网页时都会这样：

.character{
    position:absolute;
    left:500px;
    top:100px;
}

电脑上：

1920×1080

看起来正常。

但手机：

390×844

浏览器会强行缩放。

于是：

人物飞出屏幕

脑袋被切掉

对话框挡住人物

按钮跑偏



---

最简单的解决方案

不要用 px

改用：

left:50%;
top:50%;

或者：

left:30vw;
top:20vh;


---

推荐做法

人物素材：

.character{
    position:absolute;

    bottom:0;

    left:50%;

    transform:translateX(-50%);

    height:80vh;
}

解释：

left:50%;

表示：

人物中心放在屏幕中间。


---

transform:translateX(-50%);

表示：

让人物真正居中。


---

height:80vh;

表示：

人物高度占屏幕高度80%。

电脑和手机都会自动适配。


---

GalGame常用布局

例如：

.game-container{
    width:100vw;
    height:100vh;
    overflow:hidden;
    position:relative;
}

人物：

.character{
    position:absolute;
    bottom:0;
    left:50%;
    transform:translateX(-50%);
    height:75vh;
}

对话框：

.dialog-box{
    position:absolute;
    bottom:0;

    width:100%;
    height:25vh;
}

这样：

无论：

手机

平板

电脑


都会比较稳定。


---

如果你有多个角色

例如：

岚站左边

left:35%;

男主站右边

left:65%;

不要写：

left:500px;
left:1200px;

而是：

left:35%;
left:65%;


---

更推荐的方法（比赛项目）

直接使用：

.character{
    position:absolute;
    bottom:0;

    left:50%;

    transform:
    translateX(-50%)
    scale(var(--scale));
}

然后：

:root{
    --scale:1;
}

手机：

@media (max-width:768px){

:root{
    --scale:0.8;
}

}

这样手机自动缩小人物。
