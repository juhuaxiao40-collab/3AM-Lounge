# 凌晨三点的休息室 | 3AM Lounge

> 在人生迷茫时，有人陪你走一段路

## 项目简介

这是一个GalGame风格的沉浸式互动网页项目，讲述两个迷茫的人在深夜互相陪伴成长的故事。

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)

## 项目结构

```
凌晨三点的休息室/
├── index.html                  # 主页面
├── style.css                   # 样式文件
├── script.js                   # 游戏逻辑脚本
├── story.js                    # 剧情数据文件
├── editor.html                 # 剧情编辑器页面
├── editor.js                   # 编辑器脚本
├── BGM使用说明.md              # BGM添加指南
├── BGM管理系统使用说明.md      # BGM管理系统详细说明
├── 素材管理系统使用说明.md     # 素材管理系统详细说明
├── 部署指南.md                 # 项目部署教程
└── README.md                   # 项目说明
```

## 如何运行

1. **游戏运行**：直接双击打开 `index.html` 文件
2. **剧情编辑**：打开 `editor.html` 可视化编辑剧情
3. **本地服务器**（推荐）：使用 Live Server 等工具运行

## 核心理念

"没有人天生会长大。"

这不是一个AI安慰用户的项目，而是两个迷茫的人互相陪伴成长的故事。

## 角色设定

**岚 (Lan)**
- 同样迷茫的大学生
- 有对未来的焦虑
- 会害怕失败和怀疑自己
- 但仍然努力生活
